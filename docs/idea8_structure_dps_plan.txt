一、确定的目标与边界

保留现有 OSEDiff + Event LoRA（主要配置为 residual_cross_attn），冻结生成器、
VAE、文本编码器及原事件分支。另行训练轻量事件结构预测器；推理时用事件支持
的边缘结构检查增强图像，并仅优化当前样本的完整通道 UNet 中间特征。

首选接入点为最后一个 UpBlock 的输入：

  低光 RGB / 原事件输入
    → 原模型前段（DownBlocks、MidBlock、前几个 UpBlocks）
    → h0
    → h0 + M * delta       ← 结构误差经后段反传
    → 最后一个 UpBlock（保留原 Event LoRA）
    → 输出卷积 → 原 scheduler.step → VAE decode → 增强图像

delta 的形状为 [B,C,H_l,W_l]，与 h0 相同，绝不经过 rank=4 的投影瓶颈。
它是每张图像从零创建的临时张量，不是网络权重，不进入 generator state_dict。
M 是事件可靠区域缩放后的空间掩码，沿通道广播。掩码不能保证输出变化严格局部，
仍需输出保护项。

本方案不使用前后 RGB 亮度差，不恢复 ESG 正负事件分支，也不引入 idea7 的
事件亮度观测模型。第一版针对边缘/轮廓和细边缘；不能仅凭边缘损失下降就宣称
恢复了真实纹理。正式称谓为“DPS 启发的事件结构驱动主干特征在线优化”，不把
学习得到的结构约束描述为已证明的物理似然或严格后验采样。

扩散时间步保持一个；在线优化会增加前向和反向计算，不称为“一次前向”。
最初一轮仅交付计划；后续用户已授权代码实现。本轮仍不执行正式训练、远端部署或提交/推送。

四、新的事件结构输入：先解决目标时刻与空间对齐

当前 sde_event_film_dataset.py 的 event_voxel_raw 是有符号 voxel，不是原始
[t,x,y,p]；同 bin 正负事件会抵消。当前裁剪后用该区域首尾事件重新定义时间 bin，
整段事件切片可能覆盖前后相邻帧，不能直接当作当前帧的精确边缘。

新增独立的 events_structure 视图，第一版采用：
  - 原始事件 [t,x,y,p]；先核对时间单位、目标帧参考时刻 t_ref 和配对规则；
  - 围绕 t_ref 的固定短窗口，第一版明确为离线中心窗口，可使用未来事件，
    不宣称因果在线推理；窗口长度从数据时间单位和验证结果确定；
  - 5 个固定时间 bin，正负极性分开计数，得到 10 通道；
  - 时间边界先固定，再空间 crop/flip/resize，裁剪不得重定义 bin；
  - 计数使用固定配置的 log1p/尺度处理；参数只从训练数据确定并随权重保存；
  - 与 low/normal 图像及原事件视图共用几何增强参数。

保留原低光/正常光按场景、数值文件名排序后按索引配对的规则，核对正常光

先生成数据检查报告，不以猜测填充元数据。

五、事件结构预测器：独立训练，再冻结用于推理

第一版选择独立轻量 EventStructurePredictor，不让原 EventEncoder 或已有
checkpoint 承担新 10 通道输入。这样也避免只使用原最高 1/8 特征而丢失细边缘。

建议结构：10 通道输入 → 轻量 1/2、1/4、1/8 编码特征 → 多尺度融合 → 两尺度
软边缘预测；保留高分辨率浅层跳连。初始通道可设 32/64/96，作为实现起点，
不作为已验证最优配置。置信度头读取该预测器的冻结特征。

固定结构算子 Phi：RGB 转统一灰度后，使用两尺度 Gaussian + Sobel 软幅值。
输入域统一为 [0,1]；平滑尺度、幅值压缩尺度固定并版本化，禁止逐图 max
归一化把不同对比度都变成“满幅边缘”。正常光图像通过同一个 Phi 产生标签。

训练分两步，避免预测器通过把置信度降到零逃避结构监督：
  A. 不用预测置信度加权结构监督，训练边缘预测器；
  B. 冻结结构预测器，在独立校准场景上用其结构预测误差构造置信度标签，
     例如 exp(-abs(error)/tau)，只训练置信度头。tau 及映射规则随权重保存。

训练集按场景划分结构训练、置信度校准和验证子集，避免相邻帧泄漏；正式 test
不用来训练头、校准置信度或选择指导强度。验证置信度与真实误差是否相符。

推理时 C = 预测可信度 × 事件支持掩码；支持掩码由结构输入构建并允许小范围
空间容差。没有事件不等于没有边缘：无支持区域不被当作“应当平滑”的负标签。
S_E、C 只由事件和元数据产生，固定且 detach，不读取当前增强输出或 delta。

新增 train_event_structure_head.py，支持 resume_from_checkpoint。结构权重独立
保存，不重存整个生成器；记录模型结构、Phi 版本、窗口/极性/归一化配置、
场景划分、优化器/步数、随机状态及校准配置。开启指导时必须有兼容结构权重，
不能随机初始化后直接推理。原 OSEDiff + Event LoRA 不需为首版重新训练。

六、主干纠错接口与执行流程

models/unet_2d_condition.py 的 forward 新增可选 feature_guidance=None。
在 up_blocks 循环、最后一个 UpBlock 执行前对 sample 调用一次注入接口。
索引从 len(up_blocks)-1 解析，不固定写 3；返回值仍兼容原 UNet 输出。
对象只属于当前调用，不注册参数/buffer，不改变权重键或保存格式。

建议调用约定：
  apply(hidden_states, up_block_index) → corrected_hidden_states
  第一次抓取 h0.detach() 和实际形状；创建 FP32 leaf delta；后续注入
  h0 + M * delta.to(h0.dtype)。仅对 delta 求梯度，不优化网络权重。

osediff_event_film.py：
  - 向普通 UNet 路径透传 feature_guidance；
  - 复用 prepare_denoising_context，每样本 VAE latent 只采样一次；
  - context 在 no_grad 下创建，不能在 inference_mode 下创建后直接参与反传；
  - 新指导路径绕开 OSEDiffEventFiLMTest.forward 的 no_grad 装饰；
  - 纠错入口 eval、requires_grad_(False)，第一版关闭 gradient checkpointing；
    不修改原训练路径的 checkpoint 行为；
  - 整个样本完成/异常后恢复开关、移除临时状态并清理事件缓存。

每张图像的执行过程：
  1. steps=0：直接走原 baseline，不加载结构头，不额外编码/调用 UNet。
  2. 固定模型配置、采样 context、时间步和 scheduler 随机性；delta=0 得到 I0。
  3. 从事件构造 S_E、C、M；支持为空时返回 I0。
  4. 用当前 delta 生成候选，计算结构误差、输出保护项与幅度限制。
  5. autograd.grad(loss, delta)，有限性检查后更新和投影，禁止跨样本积累。
  6. 验收候选；不合格则缩小步长重试或返回已有最佳候选，初始 I0 始终可回退。
  7. 输出最终图像、损失/修正幅度/置信度/耗时/调用次数/回退原因。

旧模型保留所有冻结 Event LoRA；后段 cross-attention 重新计算，因为 Query
依赖修正后的图像特征。仅事件编码可缓存，不能缓存其后段 cross-attention 输出。

七、损失、数值域与可重复性

核心损失：
  L_struct = sum(C * Huber(Phi(I_delta)-S_E)) / (sum(C)+eps)
  L_low    = 低通(I_delta) 与低通(I0)的差异，约束亮度与颜色
  L_keep   = 低可信/非事件支持区域的 I_delta 与 I0 的差异
  L_delta  = 归一化特征改变量的正则，可选

保护参照是初始增强结果 I0，不是低光原图。除软正则外，必须限制实际注入量
M*delta 相对于 h0 通道尺度的归一化幅度；尺度用固定 h0 统计并设置数值下限。
delta=0 时 L_delta 的梯度为零，因此它不能替代第一次更新的硬幅度限制。
FP32 保存 delta、梯度、损失和统计；模型输入转换到模型 dtype 的操作保留梯度。

新增 decode 的 clamp_output=True 默认值以保持旧行为。指导可请求同一次 VAE
解码的 raw 输出：优化损失在 (raw+1)/2 上计算，另加越界惩罚；最终显示和候选
验收使用原 clamp 后图像。记录饱和比例。不得偷偷使用 straight-through clamp，
也不得仅因为 raw 图像误差下降就接受最终 clamp 后更差的候选。

候选验收只看无 GT 的结构目标和保护约束，不看测试 PSNR/LPIPS。若数值异常、
越界/保护预算超限或没有可接受改善则回退。每次重试也计入真实计算开销。

保持 scheduler.step(...).prev_sample 的原语义，不擅自换 pred_original_sample。
外部 scheduler 配置目前尚未检查；实施时记录 prediction_type、variance、
clip/threshold、实际 timestep/previous_timestep。set_timesteps(1) 不等于可
假定 step 不消耗随机数。用每样本专用 generator 状态重放同一调度噪声；如版本
接口不支持，则在局部 RNG 作用域内保存/恢复状态并验证，不扰动全局随机序列。
每个候选始终使用同一 encoded_control，不把上一次输出继续作为 scheduler 输入。

第一版启用范围：单样本、256×256 方形图、固定 checkpoint 匹配配置、Stage3
refinement off。其他尺寸/批处理/拼块模式不静默套用方形或尺度假设。steps=0
仍遵循既有支持范围。首先验证 FP32，随后验证 FP16 的梯度与饱和行为。
