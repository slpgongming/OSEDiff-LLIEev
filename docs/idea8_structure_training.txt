E-SFR 结构头训练与选模（原 H1）

范围
新增区域平衡监督、分区域/逐尺度/逐场景验证和 best/last 保存。
结构网络、事件预处理、结构算子、生成器与置信度标签保持原定义。
最终版仅保留 half 结构头。

损失与阈值
--structure_loss smooth_l1：仅用于历史监督配置兼容。
--structure_loss region_balanced：最终版新训练默认，按每个样本、每个尺度单独计算区域均值。
区域顺序为平坦/弱边缘/强边缘，依据 GT 结构划分，不依据预测结构或置信度。
--region_thresholds WEAK STRONG：默认初值 0.05 0.2，满足 0<WEAK<STRONG<1。
平坦 T<WEAK；弱边缘 WEAK<=T<STRONG；强边缘 T>=STRONG。
--region_weights FLAT WEAK STRONG：默认 1 1 1，三项均须有限且大于零。
区域内先除以自身像素数，再按权重组合；空区域跳过，并对剩余权重重新归一化。
之后对样本与尺度平均，保留平坦区惩罚，防止放大假边缘。
阈值是待确认初值，尚未从训练数据估计或验证最优。正式开跑前应查看训练 GT
结构分布，固定同一组阈值、权重、初始化、划分、事件配置、训练预算和选模规则。
首轮仅改变 structure_loss 和独立输出目录；勿用正式 test 选择阈值。

验证与 best
--best_metric auto：结构阶段按 balanced_mae，置信度阶段按 validation_loss。
--best_metric balanced_mae：区域等权绝对误差，独立于训练 region_weights。
--best_metric validation_loss：当前阶段实际验证损失；结构头建议统一用 balanced_mae。
置信度阶段结构分支冻结，禁止用 balanced_mae 选择置信度模型。
--validation_border 默认 4：仅从结构诊断去除边界，不改训练标签及原验证 loss。
--edge_tolerance 默认 2：固定像素容差的双向边缘 precision/recall/F1。
全无边缘且无误报时 F1=1；空区域指标记为 null，并记录实际计数。
常量结构图的 Pearson 相关性未定义，记为 null，不当作 0 分混入均值。

metrics.jsonl 保留原 train_loss/validation_loss/edge_mae/confidence_mae，新增：
  balanced_mae、flat/weak/strong_mae、weak/strong_bias、flat_response；
  edge_precision/edge_recall/edge_f1、spatial_correlation；
  scale_0_*、scale_1_*（顺序与 operator_config.sigmas 一致）；
  by_scene、metric_counts、global_step、selection_score、best_score、best_epoch。
诊断按样本/尺度平均，不按区域像素数加权；逐场景另行记录，供一致性检查。
负 strong_bias 表示强边缘系统性偏弱，flat_response 是 GT 平坦区预测结构均值。
不乘各自预测置信度，避免通过挑选容易区域制造改善。

每轮原子保存 checkpoint_last.pt；选模分数严格更低时才更新 checkpoint_best.pt。
同分保留较早权重；best_epoch 与旧 epoch 字段一样从 0 开始计数。
best 是所选验证指标下的最佳权重，不能自动等同于最终增强效果最佳。
候选仍需固定 72 帧增强检查和完整验证场景核实，最后才进入正式测试。

命令示意（路径由环境变量提供，本文件不启动训练）
E-SFR：
  python train_event_structure_head.py --data_root "$TRAIN_DATA_ROOT" \
    --scene_split "$SCENE_SPLIT" --output_dir "$STRUCTURE_OUTPUT_DIR" \
    --structure_loss region_balanced --region_thresholds 0.05 0.2 --best_metric balanced_mae
双卡沿用已有 torchrun 入口，每卡 batch=4 时全局为 8。global_step 只计优化器更新，
不再乘卡数。验证不补齐，每帧仅处理一次，新增统计只在验证循环外通信。

续训与校准
监督与选模配置写入 run_config 和 checkpoint。完整续训默认继承，显式改损失、
阈值、权重、选模指标、边界或容差会报错。改变监督时使用结构阶段的
--init_structure_checkpoint 仅继承权重，以新优化器开始。
旧 checkpoint 缺少监督元信息时按历史 smooth_l1 解释；缺少 best 历史时，明确从
本次续训实际验证开始记录新选择窗口，不虚构早期最佳权重。
新 checkpoint 续训恢复已有 best；移动目录时同时保留 last/best。
历史 best 早于 last 且找不到兼容 best 时，拒绝把 last 冒充 best。
置信度阶段从选中的结构 checkpoint_best.pt 初始化，保留监督/阈值定义；
置信度标签与 MSE 不变，结构参数冻结，train/calibration/validation 场景继续互斥。
模型 state_dict 和原 checkpoint 格式兼容，无需改动生成器或部署结构算子。
